# Cheat Extended

Activates only after the game's original 8776# sequence has enabled developer mode. After activation, tapping the top-left corner opens an interactive menu instead of the numeric keypad.

Includes the original developer actions for resources, elixirs, castle upgrades, battle results, daily rewards, and world progress, plus a unit manager backed by FKD Core's unit catalog.

Unit identities are namespace-qualified. Vanilla secret units use `vanilla:elf`, `vanilla:paladin`, and `vanilla:warlock`. Modded units expose their own namespace + unit id through FKD Core 0.1.20+.
